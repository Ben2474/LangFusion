Description: Many users who want to learn new languages struggle to practice and have little to no confidence because they don’t get real-time feedback and personal lessons. This app’s goal is to solve this problem by providing users interactive lessons based on their progress. This app will be used to teach users new languages and make it more engaging, effective and accessible for them. 

## Features of this App

* There is a database for user profiles, progress, quizzes, lessons, and challenges.
*	There are challenges and quizzes that will help users learn languages.
*	There is a progress dashboard with badges that you can get in lessons, quizzes, and challenges.
* There is a translation feature where users can type whatever they want, and it will translate to the language they chosed.
* There is a chatbot feature where usere can have a practice conversation with a chatbot.
* For this app, I started with languages like French, Italian, and Spanish. More languages will be added in the future.
